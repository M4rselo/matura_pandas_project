# Matura Pandas Project

## Overview
This project is an alternative solution to a Polish Matura exam task focused on data analysis.  
Instead of using Microsoft Access (as required in the exam), the task was solved using **Python and Pandas** in a **Jupyter Notebook**.

## What’s inside
- loading and processing exam data
- filtering, grouping and aggregating data with Pandas
- reproducing typical Access queries using Python
- presenting results in a clear tabular form

## Tools
- Python
- Pandas
- Jupyter Notebook

## Purpose
The project was created as a learning exercise to practice data analysis in Python and to show a more programmatic approach to solving real-world exam tasks.
